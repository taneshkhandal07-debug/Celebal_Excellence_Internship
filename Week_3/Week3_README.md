# Week 3 - Country Clustering using K-Means

## Objective
Identify countries that require aid using unsupervised machine learning.

## Dataset
Country Data Dataset

## Techniques Used
- Exploratory Data Analysis (EDA)
- Feature Scaling
- Elbow Method
- Silhouette Score
- K-Means Clustering
- PCA Visualization

## Results
- Optimal clusters selected: 5
- Cluster 2 contains countries requiring the most aid.
- Nigeria was identified as an outlier cluster.
